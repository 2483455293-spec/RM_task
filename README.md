# RoboMaster 仿真器 (RM_Simulation) 作业提交

## 📖 项目简介
本项目是一个基于 Godot 4 引擎开发的 RoboMaster 仿真器。项目实现了步兵第一人称移动射击、前哨站与基地血量护甲逻辑、能量机关激活玩法、HUD 与小地图实时反馈，并支持与外部 Python 程序进行图像与状态双通道 TCP 网络通信。

---

## 🛠️ 运行环境与启动方式

- **引擎版本**：Godot 4.x
- **运行平台**：Windows 64-bit

### 1. 启动游戏
1. 进入 `release/` 文件夹。
2. 双击 `RM_Simulation.exe`（或带控制台日志的 `RM_Simulation.console.exe`）即可直接运行。

> ⚠️ **注意**：请勿将 `.exe` 文件单独移出文件夹，必须保证它和同目录下的 `config/` 文件夹在同一层级，否则将无法读取外部配置！

### 2. 启动视觉网络接收端（可选）
若需测试图传与状态通道，请确保已安装 Python 和 `opencv-python`。在 `python_scripts/` 目录下分别运行：

```bash
# 监听 9000 端口，接收图像
python3 recv_frame.py

# 监听 9001 端口，接收状态 JSON
python3 recv_state.py
```

## 🎮 操作表 (Controls)

| 按键/操作 | 功能说明 |
| :--- | :--- |
| `W / A / S / D` | 步兵移动 |
| `鼠标移动` | 控制云台视角 (Yaw/Pitch) |
| `鼠标左键` | 发射弹丸（消耗热量与弹量） |
| `空格键` | 跳跃 |
| `E` | 启动/尝试激活能量机关（测试用） |
| `M` | 切换能量机关模式（大机关 / 小机关） |
| `P` | 暂停 / 继续比赛 |
| `R` | 重新开始比赛（重置场景） |
| `Esc` | 释放/捕获鼠标（用于离开游戏窗口） |

## 📜 游戏规则 (Rules)

1. **核心目标**：保护己方基地，摧毁敌方基地。比赛时间为 420 秒。
2. **前哨站与护盾**：
   - 基地初始处于无敌状态（护盾开启）。
   - 必须先击毁敌方前哨站（血量 1500），才能解除敌方基地的无敌护盾。
   - 前哨站带有旋转装甲板，只有弹丸以足够速度击中装甲板才会判定伤害。
3. **基地装甲展开**：当基地血量低于 2000 点时，外部装甲会展开，暴露核心。
4. **能量机关**：
   - **小能量机关**：需在 2.5 秒内击中随机亮起的指定靶心，连续击中 5 次即为成功。
   - **大能量机关**：靶心以特定的正弦波速度旋转，同样需在时间窗口内击中有效目标，共 5 组。
5. **补给机制**：进入己方补给区可缓慢恢复血量与弹药，但处于战斗状态（3秒内开火或受击）时无法补给。

## ✂️ 简化说明 (Simplifications)
- **物理与表现层**
  - 物理与地形：采用简化的平面地形与碰撞，未实现复杂的地形高低差与坡道。
  - 热量系统：简化了官方复杂的热量冷却机制，采用固定间隔线性冷却（0.1 秒降 3 点），过热时无法开火。
  - 视觉表现：使用基础几何体与发光材质代替复杂的 3D 模型，UI 与小地图采用 2D 图元绘制。
- **网络通信**
  - 网络通信：采用简化的 TCP 协议传输 MJPEG 图像流与 JSON 状态流，不包含复杂的握手与加密。
- **经济与补给系统**
  - 金币购买系统：为便于作业演示，引入了金币购买机制；作为配套，补给区每秒固定回复 10 发子弹与 10% 最大血量，未沿用官方的补给速率与冷却规则。
- **能量机关**
  - 手动激活：能量机关采用按键手动触发启动（E 键），未实现官方比赛中由裁判系统自动按时间窗口刷新、自动结算的完整流程。
  - 判定与运动保留：在手动触发的前提下，靶心的运动形式（大机关正弦波旋转、小机关随机亮起）与命中判定（有效时间窗、连续命中次数、装甲板速度阈值）均按正式比赛内容还原。
- **未实现的增益功能**
  - 所有官方增益 / Debuff 类玩法均未实现，包括但不限于：飞镖机关、符文字符机关、自动补给台回血加伤、机器人等级经验成长带来的血量/功率增益、基地自动回血、前哨站反弹装甲等。本仿真仅保留了“击毁前哨站 → 解除基地护盾”这一条核心解锁链。
- **数值与场地对齐**
  - 场地尺寸、装甲板数量与尺寸、各单位血量配置等，均尽可能对齐 RMUC 2026 官方规则；仅在小数位、精确角度阈值等工程实现细节上做了一定的取整与简化，不影响整体玩法与判定逻辑的对齐。


## ⚙️ 配置文件说明 (Config System)

本项目采用 **"外部优先，内置回退"** 的配置加载策略，由 `config_manager.gd` 全局单例管理。

- `release/config/` 存放外部 JSON 配置，玩家可自由修改。
- `res://config/` 存放打包在 exe 内部的默认配置，外部缺失时用于兜底。

**包含的配置表**：
- `match.json`：比赛时间等对局参数
- `infantry.json`：步兵移速、血量、热量、弹速等
- `buildings.json`：前哨站/基地血量、装甲展开阈值、旋转速度等
- `gameplay.json`：补给速率、能量机关参数、网络通信 IP 与端口、相机视场角等
